## 📞 SUPORTE RÁPIDO

**Sistema não responde?**
```bash
# Verificar status
vercel status

# Ver logs
vercel logs --production

# Redeploy
vercel deploy --prod
```

**Socket.io não conecta?**
- Verificar navegador console
- Checar localStorage.getItem('authToken')
- Validar CORS em backend/src/server.js

**Banco de dados offline?**
- Acessar: https://www.db4free.net
- Verificar credenciais viladajuda/ViladAjuda2026!
- Fazer backup manual se necessário
